# Security policy

## Report a problem

Report security problems privately through [GitHub private vulnerability reporting](https://github.com/hannoeru/refined-threads/security/advisories/new). Do not open a public issue.

Include the affected version, the browser, the steps that show the problem, and what an attacker could do.

## Scope

Examples of problems in scope:

- A page, post, or shared settings file that makes the extension run code.
- A way for other sites to read data that the extension stores.
- Requests to a host other than `threads.com` or `threads.net`.

Settings files contain data, not code. A shared settings file that only hides or shows posts is not a security problem.

## Supported versions

Only the latest release gets fixes.
