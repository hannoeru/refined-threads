# Keyboard navigation

**ID** `keyboard-navigation` · **On by default** · **Code** [`src/features/keyboard-navigation/`](../../src/features/keyboard-navigation/)

Moves between posts with the keyboard. The selected post gets a blue line on its left edge and scrolls into view.

| Key | Action                 |
| --- | ---------------------- |
| `j` | Next post              |
| `k` | Previous post          |
| `o` | Open the selected post |

The keys do nothing while you type in a text field, or when you hold Ctrl, Cmd, or Alt.
